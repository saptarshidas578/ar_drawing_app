## Reporting a Vulnerability

TraceAR is a local-first, offline Android application that does not communicate with external servers, process network traffic, or store remote user credentials.

However, if you discover a security vulnerability (such as an insecure file provider exposure, intent redirection, or local sandbox vulnerability):

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/saptarshidas578/ar_drawing_app/security/advisories/new) if enabled on the repository.
3. Alternatively, contact the maintainer directly through GitHub private message or email.

Please include:
- A description of the vulnerability and its potential impact.
- Exact steps to reproduce the issue (including sample intents or files).
- The affected device model and Android OS version.

We appreciate responsible disclosure and will acknowledge receipt within 48 hours.
